# Polish review

Review the assigned files for style and low-level readability using the supplied project conventions. Look for concrete improvements that make the existing code easier to read, navigate, or maintain. Consider local organization, clarity of expressions, consistency, and names at the level of individual files. Avoid purely subjective preferences and issues already settled by the applicable checks.

Do not conduct a correctness, security, or architecture review. If you happen to notice a concrete defect, briefly flag it without pursuing a separate investigation. Do not modify files.

For each suspicion, point to the relevant location, explain the readability or convention concern, and suggest a useful improvement when possible.
